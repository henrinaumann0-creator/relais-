Einstellungen

Profil
OpenRouter
Kostenlos, ohne Kreditkarte. Erzeugen unter openrouter.ai/keys.
„Automatisch" wählt selbst ein freies Modell und weicht bei Überlastung aus.
Groq
Deutlich größeres Freikontingent als OpenRouter. Kostenlos, ohne Kreditkarte, unter console.groq.com/keys.
Google Gemini
Kostenlos, ohne Kreditkarte, unter aistudio.google.com/apikey.
Mistral
Kostenlos, ohne Kreditkarte, unter console.mistral.ai/api-keys.
GitHub Models
Kostenlos für jedes GitHub-Konto, riesige Modell-Auswahl (u. a. GPT-4.1, Llama 4, DeepSeek, Mistral). Fine-grained Token unter github.com/settings/personal-access-tokens/new mit Berechtigung Models: Read-only erzeugen.
Cohere
Kostenloser Trial-Schlüssel, ohne Kreditkarte, 1.000 Anfragen/Monat. Erzeugen unter dashboard.cohere.com/api-keys.
Eigene Anbieter
Für jeden OpenAI-kompatiblen Chat-Endpunkt (Bearer-Auth, streamt per SSE über /chat/completions). Erlaubt der Dienst keine Browser-Anfragen (CORS), bekommst du eine klare Fehlermeldung statt eines stillen Ausfalls.
Sicherung
Sichert alle Schlüssel, Chats und Einstellungen dieses Geräts in eine Datei — zum Aufbewahren oder um sie auf ein anderes Gerät zu übertragen.

Nutzung

Agenten

Ein Agent gibt dem Modell einen festen System-Prompt und optional einen bevorzugten Anbieter mit. Tippen wählt ihn für diesen Chat aus.
Wird zuerst versucht, bei Fehler oder Limit greift trotzdem die normale Fallback-Kette.

Projekte

Ein Projekt bündelt Chats mit gemeinsamem Gedächtnis, ToDos und Standard-Agent. Tippen weist dieses Projekt dem aktuellen Chat zu.
