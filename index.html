Einstellungen

Zugang
OpenRouter
Anbieter nutzen
Kostenlos, ohne Kreditkarte. Erzeugen unter openrouter.ai/keys.
„Automatisch" wählt selbst ein freies Modell und weicht bei Überlastung aus.
Vercel AI Gateway
Anbieter nutzen
Ein Schlüssel, über 300 Modelle: GPT, Claude, Gemini, Llama, Qwen, Mistral und mehr über einen Zugang. Spart das Verwalten einzelner Schlüssel.
Schlüssel anlegen unter vercel.com → AI Gateway → API Keys. Neue Konten haben ein Startguthaben.
Beim Öffnen wird die aktuelle Modellliste geladen. Tippen filtert.
Groq
Anbieter nutzen
Deutlich größeres Freikontingent als OpenRouter. Kostenlos, ohne Kreditkarte, unter console.groq.com/keys.
Google Gemini
Anbieter nutzen
Kostenlos, ohne Kreditkarte, unter aistudio.google.com/apikey.
Mistral
Anbieter nutzen
Kostenlos, ohne Kreditkarte, unter console.mistral.ai/api-keys.
GitHub Models
Anbieter nutzen
Kostenlos für jedes GitHub-Konto, riesige Modell-Auswahl (u. a. GPT-4.1, Llama 4, DeepSeek, Mistral). Fine-grained Token unter github.com/settings/personal-access-tokens/new mit Berechtigung Models: Read-only erzeugen.
Cohere
Anbieter nutzen
Kostenloser Trial-Schlüssel, ohne Kreditkarte, 1.000 Anfragen/Monat. Erzeugen unter dashboard.cohere.com/api-keys.
Claude (kostenpflichtig)
Anders als die übrigen Anbieter: kein Gratis-Kontingent. Jede Nachricht zieht echtes Guthaben von deinem Konto auf platform.claude.com ab. Deshalb standardmäßig aus, auch wenn ein Schlüssel hinterlegt ist.
Claude aktivieren
Erzeugen unter platform.claude.com/settings/keys.
Eigene Anbieter
Für jeden OpenAI-kompatiblen Chat-Endpunkt (Bearer-Auth, streamt per SSE über /chat/completions). Erlaubt der Dienst keine Browser-Anfragen (CORS), bekommst du eine klare Fehlermeldung statt eines stillen Ausfalls.
Verhalten
Profil
Gedächtnis
Gilt in jedem Chat, unabhängig von Modell, Agent oder Projekt. Die KI kann Einträge selbst hinzufügen, wenn du es im Chat bittest ("merk dir …") -- hier verwaltest du sie manuell.
Team-Modus
Mitglieder tauschen sich aus
Nach der ersten Runde liest jedes Mitglied die Beiträge der anderen und kann Fehler, Widersprüche oder Lücken benennen. Das macht die Zusammenfassung deutlich verlässlicher, kostet aber eine zweite Anfrage pro Mitglied — bei Anbietern mit knappem Limit relevant.
Daten und Sicherheit
Sperre
Mit einer PIN werden alle Zugangsschlüssel verschlüsselt gespeichert (AES-256). Ohne PIN liegen sie im Klartext im Browser-Speicher und wären für jeden lesbar, der dieses Gerät benutzt.
Wichtig: Ohne diese PIN sind die Schlüssel nicht mehr lesbar. Es gibt keinen Ersatzweg.
Sicherung
Sichert alle Schlüssel, Chats und Einstellungen dieses Geräts in eine Datei — zum Aufbewahren oder um sie auf ein anderes Gerät zu übertragen.

Agenten
